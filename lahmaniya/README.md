# لحمانيا

تطبيق موبايل (ويب) لطلب **لحمانيات** و**مرتديلا** مع توصيل لباب البيت.

## التشغيل

```bash
cd lahmaniya
npm install
npm run dev
```

افتح الرابط على الموبايل أو من أدوات المطوّر بوضع الهاتف.

## الميزات

- قائمة لحمانيات ومرتديلا وباقات
- اختيار الكمية والسلة
- اختيار يوم التوصيل + عنوان البيت
- تأكيد الطلب (محلياً في المتصفح — MVP بدون باكند)

## البناء

```bash
npm run build
```
